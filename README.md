# 日影シミュレータ / Shadow Simulator

ブラウザで建物の影を確認するオープンソースのWebアプリです。公開中の画面は [shadow.datagen-pro.com](https://shadow.datagen-pro.com/) で確認できます。

## このリポジトリの内容

- `public/`: 静的サイト、日影計算と表示のJavaScript、地域案内ページ
- `tests/`: 公開した計算・画面ロジックの単体テスト
- `.github/ISSUE_TEMPLATE/`: 不具合報告、改善提案、公開見本への意見受付

地域別の3D都市モデルは外部データとして配信されます。このリポジトリにタイルデータ、配信設定、運用記録は含みません。実際の公開サイトへの反映は、このリポジトリへの変更だけでは行われません。

## ローカルで試す

```sh
npm ci
npx serve public
```

表示されたローカルURLをブラウザで開いてください。地図や3D都市モデルの表示にはインターネット接続が必要です。単体テストは `npm test` で実行できます。

## 利用上の注意

日影や建物データは概算確認用です。法令適合や設計・取引上の判断には、出典、データの収録範囲、現地条件を別途確認してください。画面内の案内も参照してください。
